# Methuselah

Proposed, not built. No judge yet; it is written by hand, by a person, when this problem is picked.

The longest-lived seed inside an 8 × 8 box in Conway's Game of Life.

**The agent (yours).** The seed (and the search that found it). The judge runs Life itself.

**The check.** Settles (periodic, gliders aside) or reaches 50,000 generations.

**The score.** Generations until stable. R-pentomino 1,103; Acorn 5,206.
