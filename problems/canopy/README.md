# Canopy

Proposed, not built. No judge yet; it is written by hand, by a person, when this problem is picked.

After M_5_1_01's recursive branching: grow a tree that catches the most overhead light for the least wood.

**The agent (yours).** The growth rule (recursive, L-system or space colonization).

**The check.** One connected tree from the root, no crossings, pipe-model thickness within 10%, leaves only on tips.

**The score.** Sun rays from three commit-seeded angles caught per unit of wood. The easiest measure here to get subtly wrong.

Full proposal: the project's `visual-problems/visual-problems.md`.
